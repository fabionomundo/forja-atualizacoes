# FORJA — atualizações

Este repositório só hospeda as versões publicadas do FORJA Desktop, para que o app instalado
possa se atualizar sozinho. Não há código aqui.

- Cada versão é uma *release* com o pacote do app e o `latest.json` que o app consulta.
- Todo pacote é assinado; o FORJA instalado recusa qualquer pacote cuja assinatura não confira.
- Seus processos, conversas e documentos ficam na sua máquina e nunca passam por aqui.
